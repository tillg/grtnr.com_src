Je cherche un éditeur Markdown adéquat. Voici les scénarios d'utilisation et les critères que j'ai en tête :

- Je prévois de l'utiliser comme éditeur pour écrire mon journal intime.
- Je veux que l'éditeur soit agréable
- Je veux voir les images dans la prévisualisation (ou dans l'éditeur lui-même) immédiatement
- Je veux un support, par exemple lors de l'entrée du lien vers une image, il devrait me montrer les fichiers d'images dans le répertoire - au moins aussi bien que VS Code le fait...

Voici les éditeurs que j'ai examinés ainsi que les **Avantages** & **Inconvénients** :

- **[Byword](https://bywordapp.com)** : 🛑 Ne montre pas les images dans la prévisualisation
- **[MacDown](https://macdown.uranusjr.com)** : 🛑 Montre les images dans la prévisualisation, mais n'a pas de support pour entrer des références aux images et scintille beaucoup : J'ai l'impression qu'il redessine toute la page à chaque caractère que j'entre... C'est agaçant !
- **[Abricotine](https://github.com/brrd/abricotine/tree/master)** : A l'air bien, il montre les images. Avantages & Inconvénients :

- **Avantage** : Je n'ai qu'une seule fenêtre : L'écriture et la prévisualisation se font dans le même panneau - ce qui est une expérience agréable à mon avis.
- **Avantage** : Il supporte bien l'ajout d'images : Avec un dialogue approprié, même avec des raccourcis 😜
- **Avantage** : C'est Open Source
- **Inconvénient** : Mes photos prises avec l'iPhone apparaissent à l'envers. Comme de nombreuses applications ont ce problème, je l'attribue à un problème spécifique au Mac - et c'est facile à corriger...
- **Inconvénient** : Il se bloque souvent. Cela semble se produire principalement lorsque j'ouvre/crée un nouveau document.

- **[Notable](https://notable.app)** : 🛑 Agréable sur Mac, mais pas de prévisualisation d'image ni de support d'insertion d'image.
- **[Obsidian](https://obsidian.md)** : C'est une chose totalement différente, je devrai découvrir plus tard...
