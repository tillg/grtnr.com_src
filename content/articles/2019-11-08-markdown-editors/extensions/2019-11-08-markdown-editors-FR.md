Je cherche un éditeur Markdown adéquat. Voici les scénarios d'utilisation et les critères que j'ai en tête :

- Je prévois de l'utiliser comme éditeur pour écrire mon journal.
- Je souhaite que l'éditeur soit agréable.
- Je veux voir les images dans l'aperçu (ou dans l'éditeur lui-même) immédiatement.
- Je veux un support, par exemple lors de l'entrée du lien vers une image, il devrait me montrer les fichiers d'images dans le répertoire - au moins aussi bien que le fait VS Code...

Voici les éditeurs que j'ai examinés ainsi que les **Avantages** & **Inconvénients** :

- **[Byword](https://bywordapp.com)** : 🛑 Ne montre pas les images dans l'aperçu.
- **[MacDown](https://macdown.uranusjr.com)** : 🛑 Montre les images dans l'aperçu, mais n'a pas de support pour entrer des références aux images et scintille beaucoup : On a l'impression qu'il redessine toute la page à chaque caractère que j'entre... C'est agaçant !
- **[Abricotine](https://github.com/brrd/abricotine/tree/master)** : A l'air bien, montre les images. Avantages & Inconvénients :

- **Avantage** : Je n'ai qu'une seule fenêtre : L'écriture et l'aperçu se font dans le même panneau - ce qui est une expérience agréable je pense.
- **Avantage** : Il supporte bien l'ajout d'images : Avec un dialogue approprié, même avec des raccourcis 😜
- **Avantage** : C'est Open Source
- **Inconvénient** : Mes photos prises avec l'iPhone apparaissent à l'envers. Comme beaucoup d'applications ont ce problème, je l'attribue à un problème spécifique au Mac - et c'est facile à corriger...
- **Inconvénient** : Il se bloque souvent. Cela semble se produire principalement lorsque j'ouvre/crée un nouveau document.

- **[Notable](https://notable.app)** : 🛑 Agréable sur Mac, mais pas d'aperçu d'image ni de support d'insertion d'image.
- **[Obsidian](https://obsidian.md)** : C'est une chose totalement différente, je devrai découvrir plus tard...
