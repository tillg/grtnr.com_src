I want to learn SketchUp. Here's a curated list of free online resources for beginners.

## Official Resources

| Resource                                                                                      | Format        | Description                                                                                              |
| --------------------------------------------------------------------------------------------- | ------------- | -------------------------------------------------------------------------------------------------------- |
| [SketchUp Campus](https://learn.sketchup.com/)                                                | Video courses | Official learning platform with Fundamentals courses (5.0 rating). Covers all core tools and techniques. |
| [Getting Started in SketchUp](https://help.sketchup.com/en/sketchup/getting-started-sketchup) | Documentation | Official guide covering interface navigation, templates, units, toolbars, and preferences.               |

## Recommended Learning Path

1. **Start with** [SketchUp Free](https://app.sketchup.com/) (browser version, no download)
2. **First course:** [MasterSketchUp Beginner Course](https://mastersketchup.com/courses/sketchup-free-for-beginners/) or [SketchUp Campus Fundamentals](https://learn.sketchup.com/)
3. **Practice projects:** Follow along with [The SketchUp Essentials](https://www.thesketchupessentials.com/) on YouTube
4. **Reference:** Keep [SketchUp Help docs](https://help.sketchup.com/en/sketchup/getting-started-sketchup) bookmarked
