# Spec Iteration Skill

1. Read the spec document the user references.
2. CAREFULLY scan for ALL user annotations: '->' arrows, [ACCEPTED], [REJECTED], [DECISION], inline comments.
3. For each annotation, apply the user's decision:
   - Remove rejected options entirely
   - Promote accepted options to definitive statements
   - Resolve open questions with the user's indicated choice
4. Produce a clean, consolidated spec with no option blocks remaining.
5. Ask the user to review before proceeding to implementation.
